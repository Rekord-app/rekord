# Sicherheitslücken melden

Bitte vertrauliche Fehler über [GitHub Private Vulnerability Reporting](https://github.com/Rekord-app/rekord/security/advisories/new) melden. Private Meldungen sind für dieses Repository aktiviert. Kein öffentliches Issue mit Zugangsdaten, echten Freigabelinks oder privaten Aufnahmen erstellen.

Hilfreich sind betroffene Version/Commit, Betriebssystem oder Node-Version, reproduzierbare Schritte mit synthetischen Daten und die erwartete Wirkung. Bitte keine fremden Systeme oder Daten testen.

Der Maintainer prüft eingehende Meldungen; es gibt derzeit keine garantierte Reaktionszeit oder bezahlten Support. Sicherheitskorrekturen werden für den aktuellen Entwicklungsstand vorbereitet und in den Release-Hinweisen dokumentiert. Ältere Releases erhalten keine zugesicherten Backports. Ein lokal bestandener Test ist keine unabhängige Sicherheitsprüfung.
